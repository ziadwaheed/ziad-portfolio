## Before publishing

Open `index.html` and replace the placeholder links:

1. Replace `https://www.linkedin.com/` with your LinkedIn profile URL.
2. Replace `https://github.com/` with your GitHub profile URL.
3. Replace `YOUR_EMAIL@example.com` with your real professional email.
4. Replace the project GitHub link with the actual Customer Segmentation repository URL.
5. Export your final resume as `Ziad_Ibrahim_Resume.pdf` and place it inside `assets/resume/`.
6. Update any course names or education wording if needed.

## Preview locally

Double-click `index.html`, or in VS Code use the Live Server extension.

## Deploy to Cloudflare Pages

### Option A — Direct Upload
1. Sign in to Cloudflare.
2. Go to **Workers & Pages**.
3. Choose **Create application** → **Pages**.
4. Choose the option to upload static assets / direct upload.
5. Upload the contents of this portfolio folder.
6. Cloudflare creates a temporary `pages.dev` URL.

### Connect your custom domain
1. Open your Pages project in Cloudflare.
2. Go to **Custom domains**.
3. Choose **Set up a custom domain**.
4. Enter `ziadibrahim.me`.
5. Follow Cloudflare's DNS confirmation steps.
6. After DNS and certificate setup complete, your site will be available at:
   `https://ziadibrahim.me`
